SOLMAR HEAT is an original open-world crime game set in Solmar City: explore a drivable city with traffic and pedestrians, steal cars, evade the police as your wanted level rises, fight, and run six story missions — with a HUD, minimap, start screen, and save. The game is plain static files (HTML + ES modules, no libraries, no network requests) and runs entirely in a desktop browser, offline.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
